MAPA EDITOR -

Legenda
Como editar o mapa mental

Seleção e foco

  • Clique num nó do canvas para focá-lo (anel de destaque).
  • O Explorer lateral sincroniza com o nó focado — e o inverso também.
  • Duplo-clique no nó (fora do modo Adicionar) renomeia inline (Enter confirma, Esc cancela).

Modos de ferramenta (barra inferior)

  • Mover — arraste um nó e solte sobre outro para mudar o pai (hierarquia). A raiz do site não se move.
  • Link — clique origem → destino; cada extremidade recebe terminal, papel, fase, bitola etc. Vários links no mesmo par são permitidos. Categorias: Circuito, Serviço, Lógico, Dados.
  • Conectar — arraste para criar dependência semântica (ciclos bloqueados).
  • Adicionar — clique num nó-pai para criar um filho. O fundo do canvas nunca cria itens.

Criar, excluir e ramos

  • Criar filho — botão no dock ou tecla Insert (com nó focado).
  • Excluir — botão no dock ou Delete; confirme no diálogo. Use Desfazer para reverter.
  • Copiar / Recortar / Colar — Ctrl+C / Ctrl+X / Ctrl+V no ramo focado.

Navegação e Visualização

  • Arraste o fundo para pan; roda do mouse faz zoom no cursor.
  • Zoom Pan — arrasta o display inteiro.
  • Zoom Realtime — arraste ↑ aproxima / ↓ afasta.
  • Zoom Window — arraste um retângulo na área a ampliar.
  • Zoom Extend — enquadra todo o modelo no display.
  • Badge no canto do nó colapsa/expande a subárvore.

Histórico e propriedades

  • Desfazer / Refazer — botões ↩️ ↪️ na barra superior ou Ctrl+Z / Ctrl+Y.
  • Propriedades — guia superior: TAG, fabricante, status, valor e classificação do nó focado.
  • Visualização — Zoom Pan, Realtime, Window e Extend no display do mapa.
  • Aparência — tema, tamanho dos nós, conectores e opções de exibição.
  • Saída — salvar, imprimir e exportar (PNG, PDF, JSON, Schema EAM).

Evidência fotográfica

Circuito físico

Trechos na ORDEM FÍSICA (origem → destino). Cada trecho aponta para um item e carrega os atributos físicos daquele ponto (posição no quadro, disjuntor, bitola, fase, comprimento).

Mapa de Circuito —

O circuito é um caminho ordenado (esquerda → direita). Os rótulos em cada nó mostram posição, disjuntor, bitola e fase daquele ponto.

Pasta raiz no PC ou VPS. A plataforma só guarda controle; fotos, PDFs e laudos ficam no disco, por site.
